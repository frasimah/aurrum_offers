НОТАЦИЯ РАЗМЕРОВ

Высота помечается «H.» или «H» сразу за числом, часто без пробела и с
точкой: «202x241x92H.», «58x45x58H.cm», «Ø 40x35H.cm», «160x45x73H cm».
Точка и «cm» к числу не относятся.

Строку копируй дословно — но НЕ считай габаритом изделия числа с этими
пометками, они описывают деталь, а не предмет целиком:

  H.B.  высота изголовья      «202x241x92H. - H.B.36cm»  -> изделие 202x241x92
  H.S.  высота сиденья        «70x74x91H. - H.S.42cm»    -> изделие 70x74x91
  THK.  толщина столешницы    «Ø 120x65H. - THK.3cm»     -> изделие Ø120x65
  D.    глубина сиденья, если стоит отдельно после дефиса

Правило простое: габариты изделия стоят ДО первого дефиса. Всё, что после
дефиса с буквенной пометкой, — размер детали.

Круглые изделия: «Ø 220 cm» — только диаметр, высоты нет и не должно быть.
Текстиль (плед, подушка, ковёр): «220x140 cm», «50x50 cm» — два числа,
высоты нет. Не придумывай третье.

ТИПЫ ПРЕДМЕТОВ

Тип обычно стоит последним словом в адресе товара: -bed, -chair, -sofa,
-armchair, -console, -coffee-table, -side-table, -bedside-table,
-floor-lamp, -suspension, -chandelier, -rug, -trolley, -trunk.
Соответствия: suspension и chandelier -> Люстра, floor lamp -> Торшер,
table lamp -> Настольная лампа, console -> Консоль, bedside table ->
Тумбочка прикроватная, coffee/side table -> Стол.

Плед (throw), подушка (cushion), тележка (trolley), сундук (trunk), ваза,
поднос — это «Другое». Не подбирай похожий тип.

ИСПОЛНЕНИЯ

Когда у изделия несколько размеров, страница перечисляет их подряд в одном
абзаце. Это РАЗНЫЕ ИСПОЛНЕНИЯ: каждое должно стать отдельной записью в
variants со своей строкой размеров. Не склеивай их в одну строку — иначе
менеджер увидит один размер из пяти и не узнает об остальных.
