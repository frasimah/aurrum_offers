# Henge

Мебель ручной работы, собственный сайт. Случай, ради которого в цепочке
остаётся Firecrawl.

## Точка входа

```
https://www.henge07.com/products/<раздел>/<модель>
```

Осторожно с поиском: есть музыкальный лейбл с похожим названием, и поисковая
выдача уводит на него. Домен только этот.

## Доступ

**Нужен рендер.** Обычный запрос отдаёт около пятисот знаков — страница
целиком собирается скриптами, в исходном HTML нет ни описания, ни размеров,
ни ссылок на товары. Один из двух брендов, где без отрисовки не обойтись
(второй — Versace Home с ответом 403).

## Где габариты

**На странице**, строкой в сантиметрах, без буквенной пометки высоты.
Оси приходится расставлять по порядку значений, и карточка честно
помечает это как предположение.

## Как отличить техлист

Товарных PDF на странице нет.

## Ловушки

- **Раздел в адресе смешанный** — диваны и кресла лежат вместе. Тип по
  разделу здесь не определяется, и это правильно: отбор намеренно
  отказывается угадывать, когда в адресе видны признаки двух разных типов.
- Отделки заданы отсылкой к каталогу материалов, а не перечнем: в карточку
  приезжает общая формулировка, а не конкретный артикул.
- Пометки высоты нет, поэтому объём считается по осям, расставленным
  предположительно. Для габаритного предмета это стоит проверить глазами.

## Приёмка

*Не для модели: значения ниже сверяет `check_lookup.py`.*

`/products/sofas-and-armchairs/leather-armchair-metal-structure-radical` —
тип «Кресло», габариты 135 / 100 / 65 со страницы, техлиста нет,
тип по адресу не определяется.
