# Porada

Мебель из массива, собственный сайт. Образцовый случай техлиста.

## Точка входа

```
https://www.porada.it/prodotto/<модель>          итальянская версия
https://www.porada.it/en/products/<раздел>        разделы каталога
```

Страница товара живёт по итальянскому адресу даже в английской версии сайта.
Раздел в адресе товара отсутствует, поэтому тип по адресу не определяется —
только по содержанию страницы.

## Доступ

Обычный HTTP, рендер не нужен.

## Где габариты

**В техлисте.** На странице их нет: размеры показаны чертежами, а варианты
исполнения перечислены буквенными обозначениями без чисел.

## Как отличить техлист

Имя файла содержит слово «техлист» и название модели — отбор по имени работает
надёжно. Посторонних PDF на странице обычно нет.

## Ловушки

- **Дюймы идут через запятую, без скобок.** Каждый сантиметровый размер
  продублирован дюймовым, и в общем перечислении они неотличимы от габаритов.
  Это дороже, чем кажется: дюймовое значение принималось за высоту, объём
  завышался в полтора раза, а объём — это транспорт по ставке за кубометр.
- **Диаметр записан диапазоном через тире**, а не через дробь. Изделие
  выпускается в нескольких диаметрах, берётся наибольший.
- **Высота не помечена буквой.** Среди перечисленных чисел она единственная,
  что не является диаметром, — по этому признаку и определяется.
- Стол выпускается круглым, овальным, эллиптическим и прямоугольным.
  Это разные исполнения, а не разные изделия.

## Приёмка

*Не для модели: значения ниже сверяет `check_lookup.py`.*

`/prodotto/infinity` — тип «Стол», габариты из техлиста, высота не должна
оказаться диаметром. Строка размеров из этого техлиста уже стоит эталоном
в разборе размеров.
