# Luxury Living Group

Один профиль на шесть марок: они живут на общем движке, с одинаковым
устройством страниц и адресов.

| Марка | Раздел |
|---|---|
| Bentley Home | `/collections/bentley-home-all-products` |
| Bugatti Home | `/collections/bugatti-home-all-products` |
| Dolce & Gabbana Casa | `/collections/dolce-gabbana-casa-all-products` |
| Luxence | `/collections/luxence-all-products` |
| Trussardi Casa | `/collections/trussardi-casa-all-products` |
| Versace Home | `/collections/versace-home-all-products` |

Fendi Casa и Elie Saab Maison здесь **отсутствуют** — их разделы отдают 404,
у этих марок отдельные сайты.

## Точка входа

```
https://luxurylivinggroup.com/products/<марка>-<модель>
```

Марка в адресе повторяет ключ из таблицы выше. Название типа предмета обычно
входит в адрес последним словом, и `type_from_url` этим пользуется.

## Доступ

Обычный HTTP, рендер не нужен. Страница отдаётся целиком.

## Фотографии — из штатной карточки магазина

Сайт на Shopify, а он отдаёт товар как JSON по тому же адресу с `.js`:

```
/products/<марка>-<модель>.js
```

Оттуда приходит **точный список фотографий изделия** — ни чужих товаров,
ни образцов материалов, ни интерьерных сцен соседних разделов. Разбирать
страницу и угадывать по именам файлов для этих марок не нужно вовсе.

Тем же JSON достоверно задаются производитель (`vendor`) и название
модели (`title`) — их берём оттуда, а не из извлечения.

Чего в нём нет: исполнений с габаритами. У изделия одна позиция
«Default Title», а размеры живут в описании и техлисте.

## Где габариты

**На странице**, строкой с пометкой высоты — тот самый вид, который разбирается
уверенно, без догадок об осях.

Техлист бывает **не всегда**. Где он есть, там полезнее страницы: даёт таблицу
исполнений с артикулами и признаком выбора.

## Как отличить техлист

На каждой странице лежит посторонний PDF — заявление о доступности. Отбирать
надо по имени файла: техлист назван по модели, посторонний — нет. Брать
первый попавшийся PDF нельзя.

## Ловушки

- **Исполнения склеиваются в одну строку.** Когда у изделия несколько
  размеров, извлечение возвращает их все одной строкой габаритов, а список
  исполнений оставляет из одного элемента. Разделять надо самим; менеджер
  иначе увидит один размер из пяти и не узнает об остальных.
- **Полнота списка исполнений плавает** от запроса к запросу. Стабильный
  результат даёт только техлист, если он есть.
- В описании конструкции материалы перечислены сплошным текстом, отдельной
  таблицы отделок нет — роли приходится выводить из описания.

## Приёмка

*Не для модели: значения ниже сверяет `check_lookup.py`.*

- `trussardi-casa-vibes-bed` — техлист, пять исполнений, первое совпадает
  с позицией R22 рабочей книги.
- `bentley-home-mere-armchair` — габариты со страницы, техлиста нет.
- `dolce-gabbana-casa-gardenia-armchair` — габариты со страницы, тип «Кресло».
