# Комнаты в рабочей форме

Снято с `0000-Offer-20260725-AUR-FORM.xlsx` 18.08.2026. Файл лежит в
Telegram Desktop и оттуда пропадал — здесь записано то, на что опирается
разбор комнат, чтобы не зависеть от его наличия.

## Как выглядит группа

```
строка 13   A «№»  B «Производитель»  C «Описание»  D «К-во»  E «Цена, Евро» …
C14         Этаж 1                     <- только колонка C, остальное пусто
C15         Холл                       <- второй заголовок сразу за первым
A16 = 1     B16 LONGHI      C16 ARIANA…       D16 1  E16 5750   F16 =D16*E16
C17         Гостевая Спальня 1
A18 = 1     B18 FLOU        C18 MADAME…       D18 1  E18 4130
C19         Мастер Спальня 2
A20 = 1     B20 VENICEM     C20 CIRCLE…       D20 1  E20 2200
C21         Гостевая Спальня 2
A22 = 1     B22 TRUSSARDI   C22 VIBES…        D22 1  E22 15590
A23 = 2     B23 TRUSSARDI   C23 COMFY…        D23 1  E23 3850
E25 «Сумма, Евро»           F25 = =SUM(F15:F24)
```

## Что из этого следует

1. **Нумерация начинается заново в каждой комнате** — 1, 1, 1, 1, 2.
   Выгрузка сейчас нумерует сквозным `offset + 1`.
2. **Заголовков подряд бывает два** — «Этаж 1», затем «Холл»: уровней
   как минимум два.
3. **Итог охватывает весь блок вместе с заголовками** — они пустые и дают
   ноль. Подытогов по комнатам в форме нет.
4. Строка-заголовок опознаётся так: в `C` есть текст, в `A` номера нет,
   расчётных значений нет.
